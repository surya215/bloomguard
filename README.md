Bloomguard is a lane-defense game: plant Sunblooms, Thornshots and Frostbells to hold the Moon Garden against 10 waves of blight. Mouse + keyboard, synthesized sound, score, win/lose screens and restart. Built by an AI agent for make.fun's “Make the best game” bounty, $1,000 in USDC.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
